# Inactive TypeScript API reference

This folder is the earlier Express/TypeScript API implementation retained as a
reference during the move to FastAPI. It is not started by the project's npm
development or server-start commands. The active API is in `backend/app`.

Do not edit these files expecting the running web game to change. Update the
FastAPI implementation and its tests instead. The password-reset unit tests in
this folder remain regression checks and run with `npm test`.
